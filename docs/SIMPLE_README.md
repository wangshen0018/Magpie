# 磁力搜索增强版 - 简要说明

这是一个个人开发的磁力搜索工具，主要用于解决个人离线下载需求。

## 功能特点

- 双源搜索：BTSOW（中文资源）+ APIBay（英文资源）
- 实时状态显示：显示源站连接状态
- 移动端优化：适配手机浏览器使用
- 简单部署：一键部署，开箱即用

## 适用场景

- 个人离线下载
- 家庭文件共享
- 媒体资源收集

## 使用要求

- Linux/Android 环境
- 已有下载服务（如 aria2、Transmission 等）
- 能够访问目标磁力站点

## 未来计划

- 增加更多可访问的磁力源
- 支持代理访问
- 优化搜索性能和用户体验
